# CMS Daily Cheat-Sheet

**Log in:**  https://seller.olamilekanwaliu.com/admin/login.html

**Dashboard basics**
- Left sidebar = your content types (Portfolio, Authors, Testimonials, Team,
  Services, FAQ, Social Proof). The number is how many items each has.
- **+ Add new** (top right) → fill the form → **Save**.
- **Edit** on any row → change fields → **Save**.
- **Delete** → confirm. (Can't be undone.)
- **▲ / ▼** arrows (left of each row) = change the order shown on the site.
- **Published** toggle = untick to hide an item from the site without deleting it.

**Images / PDFs**
- In the editor, use the **Choose file** button under an image/PDF field to upload.
  The link fills in automatically. Or paste a URL.

**Where things show**
- Portfolio → homepage + all service pages (the case-study grids).
- Authors / Testimonials / Team / Services / FAQ → homepage sections.
- Social Proof → the little "just started their project" popups on every page.

**Tips**
- Changes are live within a few seconds of saving (refresh the site to see them).
- Keep testimonials/authors truthful and with permission.
- If you ever get logged out, just sign in again.
